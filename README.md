## 🚀 Quick Start

### 1. Clone
```bash
git clone https://github.com/OlatokunboAjayi/Quant-analysis-trading-bot.git
cd Quant-analysis-trading-bot
```

### 2. Install RiskFusion
```bash
cd riskfusion_alpha
pip install -e .[dev]
cp .env.example .env
# Add your API keys to .env
```

### 3. Start Dashboard
```bash
# Terminal 1: API
cd quant-car/apps/api
pip install -r requirements.txt
uvicorn app.main:app --port 8000

# Terminal 2: Frontend
cd quant-car/apps/cockpit
npm install && npm run dev
```

### 4. Run the Bot
```bash
# Paper trading (safe)
EXECUTION_MODE=PAPER python -m riskfusion.cli run_daily
```

🌐 Open **http://localhost:3000/control** to manage the bot!
